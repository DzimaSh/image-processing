# Прасунутая апрацоўка відарысаў і вейвлет-пераўтварэнні

[![Python Application CI](https://github.com/DzimaSh/image-processing/actions/workflows/python-app.yml/badge.svg)](https://github.com/DzimaSh/image-processing/actions/workflows/python-app.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Python Version](https://img.shields.io/badge/python-3.10%20%7C%203.11-green.svg)](https://www.python.org/)

Сардэчна запрашаем у універсітэцкі/даследчы рэпазіторый **Прасунутая апрацоўка відарысаў і вейвлет-пераўтварэнні**. Гэтая база кода прызначана для размяшчэння, тэсціравання і дакументавання прафесійных, высокапрадукцыйных модуляў апрацоўкі відарысаў.

## 📚 Лабараторныя модулі рэпазіторыя

* **Лабараторная работа 1: Вейвлет-пераўтварэнне CDF 9/7 праз сепарабельную схему ліфтынгу**
  Гатовая да выкарыстання, вектарызаваная з дапамогай NumPy рэалізацыя **біяртаганальнага вейвлет-пераўтварэння Коэна-Дабешы-Фево (CDF) 9/7** з выкарыстаннем сепарабельнай схемы ліфтынгу, цалкам адлюстраваная на **арыфметыку з фіксаванай коскай Q16** з акругленым цэлалікавым маштабаваннем.
* **Лабараторная работа 2: Двухвымерныя несепарабельныя вейвлет-пераўтварэнні і параўнітарныя банкі фільтраў**
  Сучасная рэалізацыя **абарачальнага двухвымернага несепарабельнага кватэрніённага параўнітарнага банка фільтраў (Q-PUFB)** з выкарыстаннем блокавай схемы ліфтынгу (*Рыбенкаў і Пятроўскі*), а таксама **двухвымернага несепарабельнага вейвлет-пераўтварэння CDF 9/7** з выкарыстаннем прамых двухвымерных крокаў ліфтынгу (*Давід Барына*), рэалізаваная з дакладнасцю фіксаванай коскі Q16.

---

## 🚀 Ключавыя асаблівасці

* **Мультылабараторная архітэктура:** Мае чыстую мадульную структуру, дзе Лабараторная 1 і Лабараторная 2 знаходзяцца ў сваіх уласных пакетах, падзяляючы агульную папку `shared/` для асноўнага ўводу-вываду відарысаў і метрык статыстычнай ацэнкі.
* **Арыфметыка з фіксаванай коскай (фармат Q16):** Выкарыстоўвае маштабаванне на $2^{16} = 65536$ і логіку акруглення да найбліжэйшага цэлага `(A * B + 32768) >> 16` для захавання дакладнасці, блізкай да арыфметыкі з плаваючай коскай, пры выкарыстанні чыста цэлалікавай арыфметыкі.
* **Вектарызаваныя схемы ліфтынгу:** Рэалізуе крокі ліфтынгу, аптымізаваныя з дапамогай NumPy, для надзвычайнай хуткасці выканання і ідэальнай лічбавай рэканструкцыі.
* **Сіметрычная апрацоўка межаў:** Вырашае межавыя ўмовы з выкарыстаннем паўвыбаркавых сіметрычных пашырэнняў, што прадухіляе з'яўленне візуальных межаў і артэфактаў.
* **Канвееры апрацоўкі відарысаў CLI:** Спецыяльныя CLI-прыкладанні для апрацоўкі відарысаў, генерацыі візуальных прадстаўленняў DWT, рэканструкцыі відарысаў і вываду метрык.
* **Статыстычныя метрыкі:** Вылічае сярэднеквадратычную памылку (MSE) і пікавае стаўленне сігналу да шуму (PSNR) для вымярэння дакладнай адпаведнасці рэканструкцыі.
* **Інтэграцыя CI/CD:** Наладжана з дапамогай GitHub Actions для неадкладнай праверкі фарматавання і лінтынгу праз Ruff, а таксама ахопу юніт-тэстамі праз Pytest.

## 📖 Матэматычныя асновы

* **Лаб. 1:** Схема ліфтынгу раскладае поліфазавую матрыцу біяртаганальных фільтраў CDF 9/7 на паслядоўнасць крокаў прагназавання і абнаўлення, што палягчае прамыя вылічэнні на месцы. Падрабязнасці глядзіце ў [Тэхнічнай спецыфікацыі Лаб. 1](docs/lab1_specification.be.md).
* **Лаб. 2:** Рэалізуе шматканальны двухвымерны несепарабельны параўнітарны банк фільтраў на аснове гіперкамплекснай кватэрніённай алгебры, раскладзены на тры блокавыя стадыі ліфтынгу ($U, L, V$) для адлюстравання цэлых лікаў у цэлыя без страт, а таксама двухвымернае несепарабельнае вейвлет-пераўтварэнне CDF 9/7. Падрабязнасці глядзіце ў [Тэхнічнай спецыфікацыі Лаб. 2](docs/lab2_specification.be.md).

## 🛠️ Устаноўка і настройка

1. **Кланіраванне рэпазіторыя:**

   ```bash
   git clone https://github.com/DzimaSh/image-processing.git
   cd image-processing
   ```

2. **Стварэнне віртуальнага асяроддзя:**

   ```bash
   python -m venv .venv
   # На Windows
   .venv\Scripts\activate
   # На macOS/Linux
   source .venv/bin/activate
   ```

3. **Устаноўка залежнасцей:**

   ```bash
   pip install -r requirements.txt
   ```

## 💻 Выкарыстанне

### 1. Запуск Лабараторнай 1 (сепарабельнае вейвлет-пераўтварэнне CDF 9/7 DWT)

CLI-скрыпт `scripts/run_lab1.py` запускае Лабараторную 1:

```bash
# Запуск на аўтаматычна згенераваным сінтэтычным відарысе
python scripts/run_lab1.py

# Запуск на ўласным відарысе з 3 узроўнямі раскладання
python scripts/run_lab1.py --image data/my_image.png --levels 3
```

### 2. Запуск Лабараторнай 2 (двухвымерныя несепарабельныя пераўтварэнні)

CLI-скрыпт `scripts/run_lab2.py` запускае Лабараторную 2. Вы можаце выбраць паміж кватэрніённым банкам фільтраў або двухвымерным несепарабельным пераўтварэннем CDF 9/7:

```bash
# Запуск кватэрніённага параўнітарнага банка фільтраў (ідэальная рэканструкцыя цэлых лікаў у цэлыя)
python scripts/run_lab2.py --transform quaternionic

# Запуск двухвымернага несепарабельнага вейвлет-пераўтварэння CDF 9/7 (высокадакладная рэканструкцыя)
python scripts/run_lab2.py --transform non-separable-cdf

# Запуск на вашым уласным паўтонавым відарысе
python scripts/run_lab2.py --image data/my_image.png --transform quaternionic
```

### Выхадныя візуалізацыі (захоўваюцца ў `data/output/`)

* `lab2_vis_quaternionic.png` і `lab2_vis_non-separable-cdf.png`: Візуальнае прадстаўленне каэфіцыентаў пераўтварэння.
* `lab2_recon_quaternionic.png` і `lab2_recon_non-separable-cdf.png`: Рэканструяваныя відарысы з каэфіцыентаў пераўтварэння.

## 🧪 Тэсціраванне

Мы падтрымліваем высокі ахоп тэстамі для пацвярджэння матэматычнай карэктнасці і ідэальнай абарачальнасці. Запусціце набор тэстаў з дапамогай `pytest`:

```bash
# Запуск усіх тэстаў (Лаб. 1, Лаб. 2 і метрыкі)
pytest -v

# Запуск канкрэтных тэстаў лабараторных прац
pytest tests/test_lab1.py -v
pytest tests/test_lab2.py -v
```

Усе тэсты правяраюцца аўтаматычна праз GitHub Actions пры адпраўцы комітаў (push) і стварэнні запросаў на зліццё (pull request).
